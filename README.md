# 📊 CMD-Based Advanced Unit Conversion Dashboard

TypeScriptと `tsx`（esbuild）を活用し、コマンドプロンプト上でデータの解析・視覚化を行う高度な単位変換ダッシュボードです。  
元々Python（Pandas/Streamlit）で構築されていたデータフレーム処理と時系列分析のロジックをTypeScriptの関数型アプローチ（`filter`, `reduce` 等）へと移植し、軽量かつ堅牢なCLIアプリケーションとして再構築しました。

## ⚡ 特徴と技術的アプローチ

- **ゼロ・コンフィギュレーション実行**: 環境依存の激しい `ts-node` を排し、内部で `esbuild` を使用する `tsx` を採用。ESM/CommonJSの競合を自動解決し、高速なランタイムを提供。
- **データ構造の静的型付け**: CSVからパースされる動的データを不変（Readonly）な型オブジェクトとして再定義し、実行時エラーをコンパイル段階で抑止。
- **統計・分析ロジックの移植**: Pythonにおける集計・マトリックス処理を、配列操作によるパイプライン処理で再現。カテゴリー別の利用割合や利用推移の簡易グラフ生成をCLI上で完結。

---

## 🛠️ 動作環境
- Node.js: `v18.x` 以上推奨
- パッケージマネージャー: `npm`

## 🚀 クイックスタート

### 1. リポジトリのクローン
```bash

cd ts-cli-app
2. 依存パッケージのインストール
Node.js環境に必要な型定義ファイルおよび実行ランタイムをセットアップします。

Bash
npm install
3. アプリケーションの実行
TypeScriptファイルをコンパイルなしで直接高速実行します。

Bash
